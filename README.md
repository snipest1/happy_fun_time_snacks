# Happy Fun Time Snacks 🍿

Live site: https://happyfuntimesnacks.netlify.app  
Netlify Functions + React + Mailgun contact form.

## Features
- Custom contact form
- Serverless function (Netlify)
- Mailgun integration for emails
- Deploys via GitHub → Netlify

## Dev Commands
- `npm run dev` – Start Vite dev server
- `netlify dev` – Run Netlify with functions locally
